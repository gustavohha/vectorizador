# Vectorizador de imágenes

Convierte imágenes simples (PNG, JPG, WEBP…) a SVG y a DXF para AutoCAD / corte láser, directamente en el navegador. Las imágenes no se suben a ningún servidor.

**Úsalo aquí:** https://gustavohha.github.io/vectorizador/

- Modos: logo/ícono, blanco y negro (con umbral), ilustración y detallado
- Ajustes de colores, suavizado, ruido, desenfoque y resolución
- Quitar fondo, vista de contornos, descargar o copiar el SVG
- **Corte láser:** DXF con contornos cerrados en milímetros (ancho final configurable, una capa por color) y SVG de contornos en mm

Trazado basado en [imagetracer.js](https://github.com/jankovicsandras/imagetracerjs) (dominio público).
